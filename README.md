# Pokedex

A mobile Pokédex application that allows users to explore and discover Pokémon. Users have access to:
	•	A complete Pokémon list,
	•	Detailed Pokémon information (types, height, weight, base stats),
	•	Search and navigation features.

All of this is designed to provide an intuitive and enjoyable experience. By tapping on a Pokémon’s image, users can also hear its cry, making the application more interactive and immersive.
